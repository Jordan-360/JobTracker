# Job Tracker

A simple, self-built job application tracker — built as a React learning
project to strengthen frontend fundamentals and rebuild production-style
development habits.

## Stack

- React 19 + Vite
- Plain CSS
- Browser localStorage for persistence (no backend/database)

## Status

🚧 In development — scaffolding and tooling complete, core features
in progress.

## Running locally

\`\`\`bash
npm install
npm run dev
\`\`\`
